### [DualDiT: A Conditional Dual-Output Diffusion Transformer for Joint OCT Image and Segmentation Mask Generation](http://arxiv.org/abs/2607.29337v1)
*Fernando García-Torres, Rocío del Amor, Sandra Morales 외 · 2026-07-31*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 의료 영상, 특히 주석(레이블)이 부족한 생쥐 눈의 OCT(빛 간섭 단층 촬영) 영상 분야에서 인공지능 학습을 돕기 위해, 실제와 같은 의료 영상과 함께 해부학적 구조를 정확히 구분하는 분할 마스크(영상의 특정 영역을 구분하는 그림)를 동시에 생성하는 방법을 개발하는 것이 목표입니다.

**🔧 방법론**
- DualDiT(조건부 이중 출력 확산 트랜스포머)라는 새로운 생성 모델을 제안했습니다. 이 모델은 이미지를 점차적으로 만들어내는 확산 모델에 트랜스포머(인공지능 모델의 한 종류) 구조를 적용하여 영상과 분할 마스크를 함께 만듭니다.
- OCT 영상과 분할 마스크(어떤 부분이 특정 구조인지 표시한 그림)를 VAE(이미지를 압축하고 다시 만드는 인공지능 모델)를 통해 압축된 작은 표현(잠재 공간)으로 변환하고, 이 두 정보를 합쳐서 함께 처리했습니다.
- 이 압축된 정보를 이용해 조건부 확산 과정(생성할 이미지나 마스크의 특징을 미리 알려주는 방식)을 수행하여 영상과 마스크를 동시에 생성합니다.

**📌 결론**
- DualDiT 모델이 기존의 확산 모델들보다 훨씬 더 실제 같은 의료 영상과 분할 마스크를 생성하는 데 뛰어난 성능을 보였습니다.
- 의료 전문가들이 DualDiT가 만든 가짜 영상과 실제 영상을 잘 구분하지 못할 정도로 생성된 영상의 현실감이 높았습니다.
- DualDiT로 생성된 영상과 마스크를 다른 인공지능 학습에 활용하면, 주석이 부족한 의료 영상 분야에서 질병 진단이나 분석을 돕는 인공지능의 성능을 크게 향상시킬 수 있음을 확인했습니다.

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 기존 픽셀 기반 디퓨전 모델이 이미지를 생성할 때 섬세한 부분까지 잘 표현하지 못하는 문제를, 모델을 새로 학습시키지 않고 효율적으로 개선하는 것을 목표로 합니다.

**🔧 방법론**
- 사전 학습된 디퓨전 모델의 핵심 부분은 그대로 둔 채(얼어붙은 모델), 중간 단계의 대략적인 이미지 예측과 최종 단계의 정교한 이미지 예측 사이의 차이를 활용하여 모델 스스로가 생성 과정을 이끌도록 했습니다.
- 이 '스스로 이끄는' 보조 장치(예측 헤드)를 훈련할 때, 실제 이미지가 아닌 모델이 생성한 가짜 이미지들을 사용했습니다.

**📌 결론**
- 모델의 핵심 부분을 다시 학습시키지 않고도, 이미지 생성 품질을 크게 향상시켰으며, 특히 기존 모델이 표현하기 어려웠던 섬세한 부분들을 더 잘 만들어낼 수 있게 되었습니다.
- 새로운 방법론(SSG)은 기존 모델을 전체적으로 학습시키는 데 드는 비용의 1% 미만으로 적용 가능하여 매우 효율적입니다.
- 이미지 품질 평가 지표(FID)에서 기존 모델 대비 괄목할 만한 개선을 보이며, 강력한 성능을 입증했습니다.

### [Improving scDiffusion with Sparsity-Biased Classifier-Free Guidance](http://arxiv.org/abs/2607.29043v1)
*Yu Song, Hao Sun, Ikuko Nishikawa 외 · 2026-07-31*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 단일 세포 RNA 염기서열 데이터를 실제처럼 정확하게 생성하는 확산 모델의 기존 한계를 극복하고, 더욱 효과적인 데이터 생성 방법을 제시하는 것.

**🔧 방법론**
- 새로운 '희소성 편향 분류기-자유 안내(Sparsity-Biased Classifier-Free Guidance, SB-CFG)' 기법을 제안했습니다.
- 이는 데이터를 생성할 때 특정 조건(예: '어떤 세포의 데이터를 만들어줘')에 맞춰 만들도록 돕는 기존 방식('분류기-자유 안내')을 개선한 것입니다.
- 이 방법은 조건을 주지 않았을 때('아무거나 만들어줘') 모델이 참고하는 정보를 의도적으로 불완전하고 희소하게 만들어, 특정 조건에 더욱 민감하게 반응하고 더 정확한 데이터를 생성하도록 유도합니다.

**📌 결론**
- 모델을 다시 학습시키지 않고도 (추가 학습 없이) 확산 모델의 데이터 생성 단계에 바로 적용할 수 있음을 보였습니다.
- 기존 방법에 비해 중요한 유전자들의 발현 패턴을 더 정확하게 재현하고, 세포 종류의 특성을 더 일관되게 유지하며, 데이터의 희소성(대부분의 값이 0인 특징)을 더 잘 보존하여, 생물학적으로 의미 있는 유전자 발현 특징을 더 효과적으로 잡아낸다는 것을 입증했습니다.

- 특히, 물체의 3차원 형상을 더 선명하게 만들고, 투명한 물체처럼 형태를 파악하기 어려운 부분에서도 안정적으로 잘 작동했습니다.

### [From SRA to Self-Flow: Data Augmentation or Self-Supervision?](http://arxiv.org/abs/2607.02508v1)
*Dengyang Jiang, Mengmeng Wang, Harry Yang 외 · 2026-07-02*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 디퓨전 모델 중 SRA나 Self-Flow 같은 방식이 왜 더 잘 작동하는지 그 이유를 정확히 밝히고, 이 이해를 바탕으로 모델이 그림(데이터)을 더 잘 생성하도록 학습시키는 새로운 방법을 제안하는 것이 목적입니다.

**🔧 방법론**
- 어텐션 분리(Attention Separation)라는 새로운 기술을 도입하여, 모델이 그림을 생성할 때 각 노이즈 단계(점점 깨끗해지는 과정)에서 오는 정보들이 서로 섞이지 않도록 조절했습니다. 이를 통해 어떤 정보가 성능에 중요한지 분석했습니다.
- 이러한 분석 결과를 바탕으로, 이미 있는 '자기 표현 정렬'이라는 기법에 그림의 노이즈 단계를 두 가지로 동시에 보거나, 저희가 제안한 '어텐션 분리'를 이용한 데이터 증강 방식('데이터 증강'은 모델 학습에 필요한 데이터를 더 다양하게 만드는 기술)을 결합했습니다.

**📌 결론**
- 기존 디퓨전 모델이 더 좋은 결과물을 만드는 이유는 복잡한 노이즈 단계별 정보 교환 때문이 아니라, '데이터 증강'(주어진 데이터를 더 다양하게 활용하여 모델을 학습시키는 것) 효과 때문임을 밝혀냈습니다.
- 저희가 제안한 '어텐션 분리' 기법은 그 자체로 하나의 그림을 여러 개의 다른 학습 데이터처럼 사용하게 하여 '데이터 증강' 효과를 제공함을 확인했습니다.
- 이러한 발견을 바탕으로, '자기 표현 정렬' 기법과 그림의 노이즈 단계를 두 가지로 동시에 보는 방식, 그리고 '어텐션 분리'를 활용한 데이터 증강 기법을 결합한 새로운 학습 방법이 실제 이미지를 생성하는 모델의 성능을 크게 향상시킴을 보여주었습니다.

- 두 가지 변화 상태(특징 변화율과 숨겨진 오차)를 추정하는 특별한 구조를 활용하여, 불확실성을 고려한 계산 건너뛰기(computation skipping)를 정밀하게 수행했습니다.

**📌 결론**
- 계산을 건너뛸 때 발생하는 오류를 더 정확하게 예측하여, 효율적이면서도 영상 품질 저하를 최소화했습니다.
- 다양한 비디오 생성 모델(HunyuanVideo, Wan, Open-Sora 등)에 대한 실험을 통해 전반적으로 뛰어난 성능을 보여주었습니다.
