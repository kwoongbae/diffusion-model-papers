*Qiaowei Miao, Kehan Li, Yawei Luo 외 · 2026-07-02*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 다양한 종류의 입력(텍스트, 이미지, 영상, 3D 등)을 바탕으로 움직이는 3D 이미지(시간이 흐르며 변하는 3D 물체나 장면)를 일관성 있고 고품질로 생성하는 어려움을 해결하고자 합니다.

**🔧 방법론**
- 생성된 4D 이미지(움직이는 3D)가 입력 영상이나 다양한 각도에서 본 이미지 생성 모델의 정보와 잘 맞아떨어지도록 물체의 거리나 크기 등을 정렬하는 기술.
- 움직임과 3D 형태를 동시에 정렬하여, 입력된 영상과 3D 데이터를 바탕으로 어떤 각도에서 보더라도 일관성 있는 4D 콘텐츠가 생성되도록 하는 기술.
- 4D 콘텐츠의 움직임과 형태를 학습하는 과정을 따로따로 효율적으로 진행함으로써, 생성되는 결과물의 움직임과 형태를 더 정확하고 자연스럽게 만드는 기술.

**📌 결론**
- 제안하는 Align4D 방법은 다양한 입력(X)으로부터 움직이는 3D 이미지(4D 콘텐츠)를 생성하는 데 있어 현재 최고 수준의 품질과 일관성을 달성했습니다.

### [PointDiT: Pixel-Space Diffusion for Monocular Geometry Estimation](http://arxiv.org/abs/2607.02515v1)
*Haofei Xu, Rundi Wu, Philipp Henzler 외 · 2026-07-02*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 복잡한 기존 방식 대신 간단하고 효율적인 방법으로 단일 이미지에서 3차원 형상(물체의 깊이나 모양)을 더 정확하게 예측하는 것

**🔧 방법론**
- 픽셀 공간(원본 이미지와 같은 형태의 데이터)에서 작동하는 '디퓨전 트랜스포머' 모델을 사용하여, 복잡한 중간 과정 없이 바로 3차원 점 지도(물체 각 점의 위치 정보)를 생성합니다.
- 미리 학습된 이미지 분석 모델(DINOv3)에서 얻은 이미지 정보를 활용하여 3차원 형상 생성 과정을 안내합니다.
- 기존의 압축된 잠재 공간(이미지를 압축한 작은 표현 공간) 방식 대신, 디퓨전 모델의 핵심 부분을 처음부터 학습시켜 데이터 전처리 과정을 단순화했습니다.

**📌 결론**
- 새로운 방법은 기존의 복잡한 3차원 형상 추정 모델들보다 훨씬 간단하면서도 더 뛰어난 성능을 보였습니다.
- 특히, 물체의 3차원 형상을 더 선명하게 만들고, 투명한 물체처럼 형태를 파악하기 어려운 부분에서도 안정적으로 잘 작동했습니다.

### [From SRA to Self-Flow: Data Augmentation or Self-Supervision?](http://arxiv.org/abs/2607.02508v1)
*Dengyang Jiang, Mengmeng Wang, Harry Yang 외 · 2026-07-02*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 디퓨전 모델 중 SRA나 Self-Flow 같은 방식이 왜 더 잘 작동하는지 그 이유를 정확히 밝히고, 이 이해를 바탕으로 모델이 그림(데이터)을 더 잘 생성하도록 학습시키는 새로운 방법을 제안하는 것이 목적입니다.

**🔧 방법론**
- 어텐션 분리(Attention Separation)라는 새로운 기술을 도입하여, 모델이 그림을 생성할 때 각 노이즈 단계(점점 깨끗해지는 과정)에서 오는 정보들이 서로 섞이지 않도록 조절했습니다. 이를 통해 어떤 정보가 성능에 중요한지 분석했습니다.
- 이러한 분석 결과를 바탕으로, 이미 있는 '자기 표현 정렬'이라는 기법에 그림의 노이즈 단계를 두 가지로 동시에 보거나, 저희가 제안한 '어텐션 분리'를 이용한 데이터 증강 방식('데이터 증강'은 모델 학습에 필요한 데이터를 더 다양하게 만드는 기술)을 결합했습니다.

**📌 결론**
- 기존 디퓨전 모델이 더 좋은 결과물을 만드는 이유는 복잡한 노이즈 단계별 정보 교환 때문이 아니라, '데이터 증강'(주어진 데이터를 더 다양하게 활용하여 모델을 학습시키는 것) 효과 때문임을 밝혀냈습니다.
- 저희가 제안한 '어텐션 분리' 기법은 그 자체로 하나의 그림을 여러 개의 다른 학습 데이터처럼 사용하게 하여 '데이터 증강' 효과를 제공함을 확인했습니다.
- 이러한 발견을 바탕으로, '자기 표현 정렬' 기법과 그림의 노이즈 단계를 두 가지로 동시에 보는 방식, 그리고 '어텐션 분리'를 활용한 데이터 증강 기법을 결합한 새로운 학습 방법이 실제 이미지를 생성하는 모델의 성능을 크게 향상시킴을 보여주었습니다.

### [Hierarchical Anti-Aesthetics: Protecting Facial Privacy against Customized Diffusion Models](http://arxiv.org/abs/2607.02038v1)

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 악의적인 목적으로 사용되는 맞춤형 인공지능 그림 생성 모델(디퓨전 모델, 즉 노이즈를 점점 제거하며 그림을 만드는 인공지능)이 특정인의 얼굴을 만들 때, 그 이미지의 품질을 떨어뜨려 개인의 얼굴 프라이버시가 노출되는 것을 막는 것입니다.

**🔧 방법론**
- 사람들이 '아름답다'고 느끼는 기준(미학적 단서)을 역으로 활용하여, 인공지능 그림 생성 모델이 의도적으로 '보기 좋지 않은' 이미지를 만들도록 유도하는 새로운 방법을 제안합니다.
- 이 방법은 그림 전체의 생성 품질을 떨어뜨리는 '전역적 반-미학'과 얼굴 부분에만 노이즈를 주듯 미세한 변화를 주어 신원 파악을 어렵게 하는 '지역적 반-미학' 두 가지 계층적인 접근 방식을 결합하여 사용합니다.

**📌 결론**
- 광범위한 실험 결과, 제안된 HAA 방법이 기존의 다른 방법들보다 얼굴 이미지에서 신원을 제거(프라이버시 보호)하는 데 더 뛰어난 성능을 보임을 확인했습니다.
- 이는 맞춤형 디퓨전 모델의 악용으로부터 개인의 얼굴 프라이버시를 효과적으로 보호할 수 있는 강력한 도구가 될 수 있음을 의미합니다.

### [QWERTY: Training-Free Motion Control via Query-Warped Video Diffusion Transformers](http://arxiv.org/abs/2607.01869v1)
*Kyobin Choo, Youngmin Kim, Hyunkyung Han 외 · 2026-07-02*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 사전 학습된 비디오 확산 트랜스포머(디퓨전 모델의 한 종류)에서 추가 학습 없이도 사용자가 원하는 대로 영상 속 물체의 움직임을 자유롭게 제어하는 방법을 제시하는 것이 이 논문의 목적입니다.

**🔧 방법론**
- 사용자가 직접 원하는 영상 속 물체의 움직임(예: 위치, 모양 변화)을 정의하고, 이 정보를 '광학 흐름(영상 속 물체의 이동 경로 정보)' 형태로 모델에 입력합니다.
- 비디오 확산 트랜스포머(디퓨전 모델의 한 종류)가 영상의 각 부분에 얼마나 집중할지 결정하는 내부 메커니즘(어텐션)을 조작하여, 영상 속 물체의 '의미'를 담당하는 모델의 내부 '정보 탐색 기준'을 사용자가 정의한 움직임에 따라 바꿔줍니다.
- 모델이 만들어내는 중간 단계의 노이즈(잡음) 정보를 '스스로 올바른 길을 찾는 안내자'로 활용하여, 더 안정적이고 고품질의 움직임 제어를 가능하게 합니다.

**📌 결론**
- QWERTY는 추가 학습 없이 움직임을 제어하는 기존 방법들 중에서 가장 효과적인 비디오 움직임 제어 성능을 보여주었습니다.
- 이 방법은 추가 학습(미세 조정)을 통해 움직임을 제어하는 기존의 복잡한 방식들과 비교해도 비슷한 수준의 뛰어난 제어 능력을 달성했습니다.

**🔧 방법론**
- 노이즈를 점점 제거하며 데이터를 만드는 기존 '확산 모델'의 핵심 부분(데이터에서 노이즈를 예측하는 인공지능 신경망)에 양자 컴퓨터의 원리를 이용한 '양자 신경망'을 접목하여 '하이브리드 양자 트랜스포머'라는 새로운 구조를 만들었습니다.
- 개발된 모델을 실제 양자 컴퓨팅 프로세서에 적용하여 성능을 검증했습니다.

**📌 결론**
- 모델의 크기(학습에 필요한 매개변수 수)를 기존 모델 대비 약 1000분의 1 수준으로 획기적으로 줄이는 데 성공했습니다.
- 이 모델이 만든 가상 시계열 데이터는 실제 데이터 분포와의 차이(바서슈타인 거리)를 기존 모델 대비 약 44% 줄여, 실제 데이터의 특징을 훨씬 더 정확하게 재현했습니다.
- 생성된 가상 데이터를 기존 예측 모델 학습에 추가했을 때, 실제 데이터만으로 학습한 것보다 예측 오차를 나타내는 지표(RMSE)가 최대 71%까지 감소하며 예측 성능이 크게 향상되었습니다.

### [PhysiFormer: Learning to Simulate Mechanics in World Space](http://arxiv.org/abs/2606.27364v1)
*Yiming Chen, Yushi Lan, Andrea Vedaldi · 2026-06-25*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 3D 물체가 미래에 어떻게 움직일지 물리적으로 그럴듯하게 예측하고 시뮬레이션하는 새로운 방법을 제시하는 것.

**🔧 방법론**
- 노이즈를 제거하며 데이터를 생성하는 '디퓨전 모델'과 긴 정보 속에서 중요한 것을 찾아내는 '트랜스포머'를 결합한 새로운 모델(PhysiFormer)을 제안했습니다.
- 물체를 3차원 공간 속 점들(메시의 꼭짓점)로 표현하고, 이 점들이 미래에 어떻게 움직일지를 노이즈 제거 과정을 통해 직접 예측합니다.
- 여러 물체가 함께 움직이는 상황에서 시간, 공간, 각 물체에 집중하는 '어텐션(attention)' 기술을 활용하여 효율적으로 물체들의 움직임을 분석하고 예측합니다.

**📌 결론**
- 이 모델(PhysiFormer)은 다양한 재료(딱딱하거나 탄성 있는 물체)와 복잡한 상황에서도 3D 물체의 움직임을 성공적으로 예측하고 시뮬레이션할 수 있습니다.
- 기존의 다른 예측 모델들보다 물체의 움직임 궤적(경로)이 훨씬 정확하고, 물체의 형태가 유지되는 정도나 물리 법칙을 따르는 일관성 면에서도 뛰어난 성능을 보였습니다.
- 3차원 공간에서 직접 노이즈 제거 과정을 통해 물체를 모델링하는 방식이 로봇, 컴퓨터 그래픽, 물리 설계 등 다양한 분야에서 시점에 구애받지 않고 물체의 형태를 잘 이해하는 예측 모델을 만드는 데 아주 유망한 방향임을 보여주었습니다.

### [LISA: Likelihood Score Alignment for Visual-condition Controllable Generation](http://arxiv.org/abs/2606.27192v1)
*Yanghao Wang, Hongxu Chen, Jiazhen Liu 외 · 2026-06-25*

**🔧 방법론**

- 이를 위해 보조 신경망의 특정 단계 결과물을 작은 해석 신경망으로 변환한 뒤, 조건 제어 스코어와 유사하도록 추가적인 훈련 오차(손실)를 계산하여 기존 훈련 방식과 함께 최적화했습니다.

**📌 결론**
- 다양한 이미지 및 비디오 생성 작업에서 모델 훈련 속도를 높이고 최종 생성 결과물의 품질을 개선했습니다.

### [Focusing on What Matters: Saliency-Harnessing Accurate Routing for Diffusion MoE](http://arxiv.org/abs/2606.26938v1)
*Haoyou Deng, Keyu Yan, Chaojie Mao 외 · 2026-06-25*

**🏷️ 논문 종류:** 새로운 방법론 제안

**🎯 목적:** 확산 모델이 이미지를 만들 때, '전문가 혼합(MoE)' 구조에서 이미지의 중요한 부분에 컴퓨터 자원(처리 능력)을 더 정확하게 배분하지 못하는 문제를 해결하여, 더 좋은 이미지를 생성하는 것.

**🔧 방법론**
- 모델 학습이 끝난 후에 적용할 수 있는 `SharpMoE`라는 새로운 방법을 제안했습니다.
- 이미지의 어떤 부분이 중요한지를 판단하는 `라우터(자원 분배기)`가 노이즈가 섞인 어수선한 정보 대신, 노이즈가 없는 깨끗한 핵심 정보(잠재 특징)를 보고 판단하도록 했습니다.
- 이미지를 생성하며 노이즈를 제거하는 여러 단계(경로)에 걸쳐 컴퓨터 자원 배분을 더 정밀하게 조절하는 `경로 분배 손실(trajectory routing loss)`이라는 기법을 추가했습니다.

**📌 결론**
- `SharpMoE`는 이미 잘 학습된 전문가 혼합(MoE) 모델에 쉽게 적용(플러그 앤 플레이)하여 성능을 크게 높일 수 있는 유연한 해결책입니다.
- 이 방법을 통해 기존의 확산 모델보다 훨씬 뛰어난 수준의 이미지 생성(시각 생성) 결과를 얻었습니다.

- RAG(검색 증강 생성)라는 방식을 사용하여 동영상 생성 모델에 물리 법칙 지식을 주입하는 새로운 시스템(파이프라인)을 개발했습니다.

- 데이터 필터링, RAG 메커니즘, 물리 정보 추출 등 핵심 구성 요소들이 효과적임을 다양한 실험을 통해 확인했습니다.

### [NaviCache: Test-Time Self-Calibration Caching for Video Generation](http://arxiv.org/abs/2606.26795v1)
*Zheqi Lv, Zhibo Zhu, Jinke Wang 외 · 2026-06-25*

**🏷️ 논문 종류:** 효율화·가속

**🎯 목적:** 비디오 생성 확산 모델(노이즈를 제거하며 영상을 만드는 모델)이 영상을 생성하는 데 드는 엄청난 계산 비용을 줄이면서도, 기존의 가속 방법들이 가지고 있던 정확도나 유연성 문제를 해결하는 것이 목표입니다.

**🔧 방법론**

- 확산 모델이 이미지를 개선하는 과정을 마치 비행기가 움직임을 추정하듯이 '관성 항법 시스템' 원리에 비유하여, 입력과 출력 변화의 관계를 모델링했습니다.

**📌 결론**
- 계산을 건너뛸 때 발생하는 오류를 더 정확하게 예측하여, 효율적이면서도 영상 품질 저하를 최소화했습니다.
